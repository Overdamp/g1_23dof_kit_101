# Offset Check

> ย้ายมาจาก vault ของผู้ดูแล (`02 Real Robot/Offset Check.md`) เมื่อ 10/11/2026
>
> คำสั่งในหน้านี้รันจากโฟลเดอร์ `<WS>/unitree_rl_mjlab` ใน env `g1_sdk` · `$S` = `deploy/robots/g1_23dof/scripts` (ตั้งด้วย `S=deploy/robots/g1_23dof/scripts`)

## ทำไม
2/11/2026 พี่ในแล็บแก้มอเตอร์ 25/26 ผ่านแอป Unitree Explore (วิธีไม่ทราบแน่ อาจเป็น calibrate ข้อต่อ) ถ้ามีการ calibrate **ค่าศูนย์ของข้อต่อเปลี่ยน** → มุมที่หุ่นรายงานไม่ตรงกับตอนเทรน → policy ยืน/เดินผิดท่า
policy ทนค่าศูนย์คลาดได้ราว ±0.015 rad (`encoder_bias` DR, [Observations](../03-reference/observations.md))

## ทำไมเทียบท่าห้อยแขนไม่ได้
ตอนแขวนแบบ damping ข้อต่อค้างได้ทุกที่ เทียบ 28/10 กับ 30/10 ท่าห้อยต่างกันถึง **0.3 rad** มากกว่าค่าที่ต้องการตรวจ (~0.05)

## วิธี: เทียบจุดชนสุด (hard stop)
จุดชนสุดเป็นกลไก คงที่ 28/10 บันทึกไว้ครบ 23 ข้อต่อ (`~/g1_joints_20261028_1848.csv`, เข่าขวา `_1927`)
ถ้าค่าศูนย์เลื่อน δ → **ทั้ง min และ max เลื่อน δ ไปทางเดียวกัน**

```bash
python $S/offset_check.py --network enp43s0 --joints right_elbow,right_wrist,right_shoulder
python $S/offset_check.py --network enp43s0                         # ทั้ง 23
python $S/offset_check.py --csv <log>             # จากไฟล์
```
หมุนแต่ละข้อต่อช้าๆ จนชนสุดทั้งสองทาง (ไม่ต้องกดแรง) แล้ว Ctrl-C
ผลสุดท้ายเซฟเองที่ `~/offset_check_<วันที่>_<เวลา>.txt` (เปลี่ยนด้วย `--out`, ปิดด้วย `--out ''`)

| ผล | ความหมาย | ทำต่อ |
|---|---|---|
| `OK` | ทั้งสองฝั่งห่าง 28/10 ≤ 0.03 rad | ผ่าน |
| `SHIFT +x` | สองฝั่งเลื่อนทางเดียวกัน | **ห้ามรัน policy** จดค่าแล้วคุยกัน |
| `not reached` | ฝั่งนั้นห่าง > 0.15 rad | หมุนให้สุด |
| `past 28/10` / `short` | ฝั่งเดียวเพี้ยน | ดูอีกฝั่งประกอบ |
| `no data` | มอเตอร์ offline | ดู [Incident Motors 25-26](../05-history/incident_motors_25-26.md) |

ไหล่ roll ฝั่งหุบชนลำตัวแทนจุดชนสุด → ซ้ำได้น้อยกว่า
