# Day 5: วันทดสอบหุ่นจริง

> [!warning] หน้านี้ไม่ใช่คู่มือให้ทำคนเดียว
> - ทดสอบหุ่นจริง**เฉพาะเป็นกลุ่ม**ตามกฎแลป และต้องได้รับอนุญาตจากผู้รับผิดชอบหุ่นก่อน
> - หุ่นแขวนบน gantry ตลอด เชือกรับน้ำหนักได้เสมอ
> - มีคนหนึ่งคนที่**ทำหน้าที่เดียว**คือถือรีโมทพร้อมกด **L2 + B** และพูดว่า "หยุด" ตั้งแต่หุ่นเอียง ~15°
> - ผ่าน Day 4 ครบก่อน

**เป้าหมาย:** รู้ว่าวันทดสอบมีลำดับอะไร ใช้เอกสารไหน และบทบาทของตัวเองคืออะไร
ขั้นตอนละเอียดพร้อมเกณฑ์อยู่ในเอกสารของ repo ซึ่งเป็นฉบับที่ใช้จริง ไม่คัดลอกมาไว้ที่นี่เพื่อไม่ให้สองฉบับขัดกัน

## ต่างจาก sim ตรงไหน
| | sim (Day 4) | หุ่นจริง |
|---|---|---|
| interface / domain | `lo` / 1 | การ์ดที่ต่อหุ่น (เช่น `enp43s0`) / 0 |
| IP ของเครื่องเรา | – | ต้องอยู่วง `192.168.123.x` (หุ่น: .161 low-level, .164 high-level) |
| คำสั่ง | `make deploy-sim` | `make deploy-real IFACE=enp43s0` ด่านตรวจ 4 ข้อแล้วต้องพิมพ์ `real` |
| บรรทัด DDS | `SIM, keyboard on` | `REAL ROBOT, keyboard off, remote only` **ถ้าไม่เห็นบรรทัดนี้ให้หยุด** |
| เปลี่ยนโหมด / หยุด | คีย์ `u` `v` `p` | รีโมท L2 + ↑ / R2 + A / **L2 + B** |
| ก่อนเริ่ม | – | หุ่นอยู่ debug mode (zero-torque แล้วกด L2 + R2), ปิด sim ทุกตัว, บริการบน .164 ที่ส่ง lowcmd ต้องหยุด |

## ลำดับวันทดสอบ (สรุป)
| ขั้น | ทำอะไร | ผ่านเมื่อ |
|---|---|---|
| ก่อนเริ่ม | `make doctor`, ปิด sim, ตรวจ IP, `make gain-check POLICY=v0` | 0 FAIL, PASS |
| 9.0 | `make deploy-real IFACE=enp43s0` → T1, T2 → T3 | `REAL ROBOT`, `Connected`, โหลด policy `v0` |
| 9.1 | แขวน: Passive (ตรวจ kd) → FixStand 30 s (ตรวจ kp) **ไม่เข้า Velocity ตอนแขวน** | `pd_check` ผ่าน, ไม่สั่น |
| 9.2 | หย่อนให้เท้าแตะพื้น (เชือกยังกันไว้) → R2 + A → ยืนใน Velocity | ยืนนิ่ง เอียง < 5° |
| 9.3 | เดินช้า stick ~20% → ~40% | เดินตรง |
| 9.4 | หมุน, เดินด้านข้าง ~30% | – |

ข้อไหนไม่ผ่าน**ให้หยุดแล้ววิเคราะห์** ห้ามข้ามขั้น ทำช่วงสั้นๆ (ยืน 30 s, เดิน 3–5 s) และระหว่างทดสอบห้ามใช้เครื่องเทรนหรือรันงานหนัก
