# พื้นฐานก่อนเริ่ม

8 หน้าสั้นๆ สำหรับคนที่ยังไม่เคยใช้เครื่องมือเหล่านี้ อ่านตามลำดับ หน้าละไม่เกิน 10 นาที
ทุกหน้ามีคำสั่งให้ลองพิมพ์ (ปลอดภัย ไม่แก้อะไรในเครื่อง) และคำถามท้ายบทพร้อมเฉลย

| # | หน้า | อ่านจบแล้วจะตอบได้ว่า |
|---|---|---|
| 1 | [terminal, path, cd](01_terminal_and_paths.md) | คำสั่งนี้รันจากโฟลเดอร์ไหน และทำไมถึงสำคัญ |
| 2 | [ตัวแปร environment](02_environment_variables.md) | `export` / `unset` ทำอะไร ทำไมเปิด terminal ใหม่แล้วค่าหาย |
| 3 | [conda env](03_conda_envs.md) | ทำไมโปรเจคนี้มี 2 env และต้องเปิดตัวไหนเมื่อไร |
| 4 | [make](04_make.md) | `make sim2sim` จริงๆ แล้วรันอะไร |
| 5 | [DDS, domain, interface](05_dds_domain_interface.md) | ทำไม sim กับหุ่นจริงไม่ปนกัน และ `CYCLONEDDS_URI` ต้อง set หรือ unset |
| 6 | [ROS 2 กับ Unitree SDK](06_ros2_vs_unitree_sdk.md) | สองระบบนี้ต่างกันอย่างไร, Fast DDS กับ Cyclone DDS |
| 7 | [git worktree กับ PYTHONPATH](07_git_worktree_and_pythonpath.md) | ทำไมแก้โค้ดใน worktree แล้วบางทีไม่มีผล |
| 8 | [tmux และ byobu](08_tmux_and_byobu.md) | session / window / pane, ปุ่มของสองแบบ, ปิด session ที่ค้างอยู่ |
